Purpose: 

This is a program designed to have the end user guess the correct number. 


Code Explanation:
This uses the while option along with and if and some elseif statments.  The second line of the code is what drives the "magic" number.  The code is saying that until the end user enters that number the loop will continue. 

If the end user selects a number > than the choice number they get a message that the number is too high, the same goes if they guess a number < than the choice number they will get a message that the number is too low.  

Once they enter the choice number the loop stops and a message appears that they have guessed correctly. 

I entered numbers and even words to test to make sure that the code worked correctly.  I tried negative numbers, numbers below the choice number, numbers above the choice number and even words to see if the code would break.  All seemeed good.
