# README.md

Purpose: 
The program I created checks the number of year that an employee works for SWTC.  This will determine what their service award stipend would be. 

Code Explanation: 
This uses the if and elseif statments.  I have a couple of input fields to start the coding.  One for the employee to enter their name and the next to enter their years of service.  This second line, years of service, is what actually drives the rest of the code through the if and elseif statements.  

Once they enter their years of service, the coding continues on down to figure out which "bucket" their entered years fit into. Once it finds this correct line, the loop then stops and the print message below it appears to the end user. 

What I learned about this quickly is that in this example, the coding actually had to be entered what looks like "backwards" from what you would actually read in an employee handbook.  When I originally started the coding with the 5 year option on top, it always stopped right away for anyone over 5 years and wouldn't continue down the loop.  However, when I entered the code what looks like "backwards" then it stopped on the correct bucket depending on how long the years of service actually was.
